## Proposed mechanism (please attack)

In this game every move is followed by a 3-ball stochastic spawn (huge chance-node branching).
1600 sims therefore resolve only ~2-3 plies of genuine lookahead — deaths inside that window
are visible to the tree (exactly our danger band, where corrections ARE good); everything
beyond must be carried by the leaf value function. A trained survival head injects long-horizon
knowledge (orthogonal to the prior) into every visit count; the 27-feature linear evaluator
carries ~nothing off the death-edge (project-established: its move-level diffs are noise wrt
survival). So sims were never the knowledge carrier; the leaf function is. Play strength stays
high with a weak leaf because play-time search re-runs its short lookahead every move (rolling
horizon); recorded targets at a single quiet state contain none of that.

Corollary that worries us (question 5 below): the base ep87's OWN 128ch backbone previously
failed to host a value head — a pairwise ranking head trained on 256ch-MINED data hit val_acc
0.52 (random) while the identical data trains to 0.64 on the 256ch backbone. We suspect the
mismatch was the DATA (transfer instead of matched — violating the project's own "retrain the
head per backbone on its own data" rule), not the backbone. Gate 1 tests exactly this.

## The 3-gate validation ladder (running now — bars fixed in advance)

- **Gate 1 (zero new generation, ~half a day):** survival labels straight from the existing
  7,775 games (died replays = uncensored died-within-{25,50,100,200}; capped = censored masks);
  train the survival head on ep87's FROZEN backbone; validate against a K=64-rollout p_hat set.
  **Bar: calibration r ≥ ~0.75 at H25-H100** (256ch precedent: 0.87-0.90). Fail → the backbone
  can't carry survival even matched → value-head path dead, cost one afternoon.
- **Gate 2 (~an evening):** re-search ~500 sampled states with ep87 + new head + q=2.0 @600
  sims (the exact V14 config), rollout-judge the resulting corrections vs base argmax.
  **Bar: clear wins appear in QUIET states** (FV baseline measured: 0% / 0% there). Fail → the
  head calibrates but doesn't change targets where it matters → stop.
- **Gate 3 (~a day, still no Colab):** micro-corpus (~50 probe seeds, head-guided @600/400),
  plain 3b recipe + rehearsal anchor, **ep1 ≥ base on 500 seeds, floor-first** (project rule:
  every historically-successful run improved by ep1; every failure regressed by ep1).
  Only after Gate 3 do we spend real generation/training compute.
